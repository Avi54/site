A Solution to the Dutch National Flag problem

June 22, 2025 · 1 min

Presenting a solution to the Dutch National Flag problem.

Algorithim#

def dutch(A, n): 
    i = 0
    j = 0
    k = n - 1

    while (j <= k):
        if (A[i] == 1):
            A[i], A[j] = A[j], A[i]
            i = i + 1
            j = j + 1
        elif (A[j] == 3):
            A[j], A[k] = A[k], A[j]
            k = k - 1
        else:
            j = j + 1
